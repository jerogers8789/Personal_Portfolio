# Jeremiah Rogers: Portfolio

Personal portfolio site for Jeremiah Rogers, IT Support & Cybersecurity Student.

Live: https://jerogers8789.github.io/Personal_Portfolio/

Plain HTML and CSS: no build step, no JavaScript, no trackers. `.nojekyll` tells GitHub Pages to serve the files as-is.

- `index.html`: the single-page site
- `assets/styles.css`: styles
- `assets/favicon.svg`: icon

Preview locally:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
